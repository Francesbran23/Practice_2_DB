## ⚙️ Confirmación de puesta en funcionamiento
El proyecto fue clonado desde el fork y configurado siguiendo las instrucciones del `README` original.  
Se realizaron las siguientes acciones:  
1. **Fork** desde el repositorio docente.  
2. **Clonado local** en la máquina del equipo.  
3. **Configuración y ejecución** mediante Docker Compose.  
4. **Conexión a la base de datos** a través de PgAdmin4 con las credenciales definidas en el Compose.  
5. **Verificación de funcionamiento** desde la terminal y entorno de base de datos.
